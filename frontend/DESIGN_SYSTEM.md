# Design System

## Visual Direction

The interface uses a dark, game-inspired productivity aesthetic with indigo primary actions, red-orange accents, green completion states, and slate surfaces.

## UI Patterns

- Reusable surfaces use the `card` and `card-lg` classes.
- Primary actions use `btn-primary`.
- Secondary and low-emphasis actions use `btn-secondary` and `btn-ghost`.
- Category, rarity, and status labels use the badge styles in `index.css`.
- Motion is supplied by Framer Motion for page transitions, onboarding steps, and quest feedback.
